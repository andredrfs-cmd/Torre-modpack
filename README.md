## 🔄 Como Funciona a Atualização

### **Primeira Vez (v1.0 - Já Feita):**
1. ✅ Arquivo `modpack-latest.zip` foi enviado ao repositório
2. ✅ Commit foi feito: "Add modpack v1.0 - Initial release"
3. ⏳ Próximo passo: Criar Release v1.0 no GitHub

### **Próxima Atualização (v1.1 - Como Fazer):**
1. Modifique seu modpack localmente
2. Crie novo `modpack-latest.zip` (substitua o arquivo)
3. Faça commit e push:
   ```bash
   git add modpack-latest.zip
   git commit -m "Update modpack to v1.1 - Adicionei novas mods"
   git push origin main
   ```
4. Crie nova Release com tag `v1.1` no GitHub
5. O link `/releases/latest/download/modpack-latest.zip` atualiza automaticamente!
